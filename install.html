התקנה

מתקינים פעם אחת, מבקשים בשפה חופשית

הסקיל כתוב בפורמט Agent Skills, שנתמך על ידי Claude, Codex CLI וכלים נוספים. כל סוכן אחר יכול להריץ את הסורק ישירות. צריך רק Python 3.

התקנה לפי סוכן

Claude.ai ואפליקציית Claude

ללא טרמינל
  1. מורידים את קובץ ה-‎.skill.
  2. בהגדרות, בחלק Skills, מעלים את הקובץ.
  3. מבקשים מ-Claude לבדוק נגישות של פרויקט.

Claude Code

  1. מעתיקים את תיקיית הסקיל לתיקיית הסקילים של המשתמש: 
    git clone https://github.com/jordanhemo/il-accessibility-audit.git
cp -r il-accessibility-audit/il-accessibility-audit ~/.claude/skills/
  2. פותחים סשן חדש. הסקיל נטען לבד כשמבקשים בדיקת נגישות.

לפרויקט אחד בלבד: מעתיקים לתיקייה .claude/skills/ בתוך הפרויקט.

Codex CLI

OpenAI
  1. מעתיקים את התיקייה לתיקיית הסקילים של Codex: 
    git clone https://github.com/jordanhemo/il-accessibility-audit.git
mkdir -p ~/.codex/skills
cp -r il-accessibility-audit/il-accessibility-audit ~/.codex/skills/
  2. מפעילים מחדש את Codex. בגרסאות ישנות צריך גם codex --enable skills.

לפרויקט אחד בלבד: Codex מזהה סקילים גם תחת .agents/skills/ בפרויקט.

Cursor, Gemini CLI, Aider ואחרים

  1. מעתיקים את תיקיית il-accessibility-audit/ לפרויקט.
  2. מבקשים מהסוכן: "קרא את il-accessibility-audit/SKILL.md ופעל לפיו כדי לבדוק את הפרויקט".

סוכן שמריץ פקודות יכול גם להפעיל את הסורק ישירות, כמו בסעיף "בלי סוכן" למטה.

שליחה לסוכן שלכם

לא רוצים להתקין בעצמכם? מעתיקים את ההודעה ומדביקים אותה אצל הסוכן שאתם עובדים איתו. היא מפנה אותו לדף הוראות שנכתב במיוחד לסוכנים, והוא ממשיך משם לבד.

דף ההוראות לסוכנים

איך מבקשים

אין פקודה לזכור. כותבים לסוכן בשפה חופשית, למשל:

  • תבדוק אם האתר בתיקייה הזו עומד בתקן הנגישות הישראלי ותתקן מה שאפשר
  • אני צריך דוח נגישות לפי תקן 5568 לפרויקט ה-Next.js שלי
  • חסרה לנו הצהרת נגישות? תכין לי אחת
  • Audit this project for Israeli accessibility law (IS 5568) and fix what is safe to fix.

בלי סוכן

הסורק הוא כלי שורת פקודה רגיל. מריצים אותו מתוך תיקיית הסקיל:

פקודהמה היא עושה
python3 scripts/scan.py <dir>מדפיסה את הממצאים כ-JSON. לא משנה אף קובץ.
… --format mdמדפיסה דוח בעברית במקום JSON.
… --report accessibility-report.mdשומרת את הדוח לקובץ.
… --fixמתקנת בקבצים רק את lang, dir ו-tabindex חיובי.

הצהרת נגישות של האתר

האתר נבנה לפי WCAG 2.1 ברמת AA: שפה וכיווניות מוגדרות, קישור דילוג לתוכן, ניווט מלא במקלדת עם סימון מיקוד ברור, ניגודיות תקינה במצב בהיר וכהה, וכיבוד הגדרת הפחתת תנועה.

נתקלתם בבעיית נגישות או בממצא שגוי של הסורק? דווחו ב-GitHub.
