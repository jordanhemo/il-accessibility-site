02

שתים עשרה בדיקות

קריטריוני WCAG 2.0/2.1 ברמת AA שעליהם מבוסס ת"י 5568, ועוד שתי דרישות שקיימות רק בישראל.

  • שפת העמודlang="he" בתג html. WCAG 3.1.1תיקון אוטומטי
  • כיווניות מימין לשמאלdir="rtl" לעמוד עברי. דרישה ישראליתתיקון אוטומטי
  • סדר מעבר במקלדתtabindex חיובי ששובר את הסדר. WCAG 2.4.3תיקון אוטומטי
  • הצהרת נגישותקיימת ומקושרת מכל עמוד. תקנות 2013חובה חוקית
  • טקסט חלופי לתמונותחסר, או ריק על תמונה שאינה דקורטיבית. WCAG 1.1.1הצעת פתרון
  • תוויות לשדות טופסlabel או aria-label לכל קלט. WCAG 1.3.1, 4.1.2הצעת פתרון
  • ניגודיות צבעיםחישוב יחס אמיתי מול 4.5:1 ו-3:1. WCAG 1.4.3הצעת פתרון
  • קישורים וכפתורים ריקיםאייקון בלי שם נגיש. WCAG 2.4.4, 4.1.2הצעת פתרון
  • היררכיית כותרותדילוגים, h1 חסר או כפול. WCAG 1.3.1הצעת פתרון
  • קישור דילוג לתוכןמעקף לניווט בראש העמוד. WCAG 2.4.1הצעת פתרון
  • תפקידי ARIAערך role שאינו קיים בתקן. WCAG 4.1.2הצעת פתרון
  • מדיה שמתנגנת לבדautoplay בלי השתקה. WCAG 1.4.2הצעת פתרון

04

התקנה בדקה

הסקיל כתוב בפורמט Agent Skills, שנתמך על ידי Claude, Codex CLI וכלים נוספים. כל סוכן אחר יכול להריץ את הסורק ישירות. אין חבילות להתקין, רק Python 3.

Claude

ב-Claude.ai או באפליקציה: מורידים את קובץ ה-‎.skill ומעלים אותו בהגדרות, בחלק Skills.

ב-Claude Code, כפלאגין:

/plugin install il-accessibility-audit \
  --marketplace jordanhemo/il-accessibility-audit

Codex CLI

אותה תיקייה, בתיקיית הסקילים של Codex:

git clone https://github.com/jordanhemo/il-accessibility-audit.git
mkdir -p ~/.codex/skills
cp -r il-accessibility-audit/il-accessibility-audit ~/.codex/skills/

בגרסאות ישנות: codex --enable skills.

Cursor, Gemini CLI ואחרים

מעתיקים את התיקייה לפרויקט ומבקשים מהסוכן לקרוא את SKILL.md, או מריצים את הסורק ישירות:

python3 il-accessibility-audit/scripts/scan.py . \
  --format md --fix --report accessibility-report.md
  • תבדוק אם האתר בתיקייה הזו עומד בתקן הנגישות הישראלי ותתקן מה שאפשר
  • אני צריך דוח נגישות לפי תקן 5568 לפרויקט ה-Next.js שלי
  • חסרה לנו הצהרת נגישות? תכין לי אחת

06

מה החוק דורש

תקנות שוויון זכויות לאנשים עם מוגבלות (התאמות נגישות לשירות), תשע"ג-2013 מחייבות כל אתר שנותן שירות לציבור לעמוד בתקן ישראלי 5568, שהוא הגרסה הישראלית של WCAG ברמת AA.

מעבר לדרישות הטכניות, החוק מחייב לפרסם הצהרת נגישות המקושרת מכל עמוד, ובה רמת ההתאמה, ההתאמות שבוצעו, פרטי רכז הנגישות ותאריך העדכון. נציבות שוויון זכויות רשאית להטיל עיצומים כספיים על אתרים שאינם עומדים בדרישות.

הסקיל מבצע סריקה סטטית של קוד המקור ומוצא את רוב בעיות המבנה והסימון. הוא אינו רואה תוכן שנוצר בזמן ריצה ואינו מחליף בדיקה של בודק נגישות מוסמך או ייעוץ משפטי.

הצהרת נגישות של עמוד זה

העמוד נבנה לפי WCAG 2.1 ברמת AA: שפה וכיווניות מוגדרות, קישור דילוג לתוכן, ניווט מלא במקלדת עם סימון מיקוד ברור, ניגודיות תקינה במצב בהיר וכהה, וכיבוד הגדרת הפחתת תנועה.
