# il-accessibility-site

דף הנחיתה של [בודק נגישות ישראלי](https://github.com/jordanhemo/il-accessibility-audit), סקיל לסוכני AI שבודק אתרים לפי תקן ישראלי 5568.

אתר סטטי ללא build: `index.html` בשורש, פרוס ב-Vercel. קבצים לסוכני AI: [`for-agents.md`](for-agents.md), [`llms.txt`](llms.txt).

הקוד של הסקיל עצמו נמצא בריפו הנפרד. דיווחים על הסקיל: שם. דיווחים על האתר: כאן.
